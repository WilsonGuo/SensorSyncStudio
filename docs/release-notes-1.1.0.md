# Sensor Sync Studio 1.1.0 发布说明

发布日期：2026-11-07
适用固件：Sensors-SYNC V3.1.0（协议 1.1）
新增硬件：R1 网络 RTK 模块（串口配置）

## 新增：R1 RTK 设备集成

入口在菜单「功能 → RTK 设备」，独立对话框，使用第二个串口，与同步器的 DEBUG 口互不影响。

### 状态

解析 R1 输出的 NMEA 语句，实时显示：

- 定位状态（无效 / 单点定位 / 差分定位 / RTK 浮动解 / RTK 固定解，按等级着色）
- 卫星数、HDOP、海拔、经纬度（已换算为十进制度）
- 差分龄期（未收到差分时显示「未收到差分」，可用于判断 CORS 是否生效）
- 航向（来自 HDT）、速度（来自 VTG）、最近更新时间

### CORS 账号

- 「读取当前配置」发送 `$gnp,*55`，回填服务器、端口、挂载点、用户名与「上传 GGA」开关
- 「写入设备」发送 `$snp,<服务器>,<端口>,<挂载点>,<用户名>,<密码>,<0/1>,*XX`，校验和按 `$` 与 `*` 之间字节异或计算
- 设备不回读密码，因此密码框默认留空并支持「显示/隐藏」切换；密码为空时写入会被额外提示「会清除原有密码」

### 语句输出

- 支持 GGA / RMC / GSA / GSV / HDT / VTG 六条语句，各自选择 关闭 / 10 Hz / 5 Hz / 2 Hz / 1 Hz
- 只下发改动过的行：关闭用 `unlog <语句>`，设置用 `<语句> <周期秒>`
- 末尾自动追加 `saveconfig`，界面提示重启设备后生效

### 原始命令

任意命令输入框 + 完整收发日志，底部提供「清空」按钮；日志上限 4000 行。

## 界面修复

- 修复高 DPI（150% 缩放）或全屏时右侧栏控件被压扁、按钮文字裁切、设置按钮与端口表重叠的问题：右侧栏改为可滚动、最小宽度保护、内边距收紧
- 移除「串口与设备」「端口状态」面板的最小化按钮
- 「端口与相机设置…」入口移到端口状态面板右上角
- 修复菜单项文字被裁切（补 `QMenu` 最小宽度与项目内边距）
- R1 图标采用透明背景，随深色/亮色主题自动适配

## 兼容性

- 同步器部分协议、命令行与 1.0.4 完全一致，固件无需升级
- R1 需通过 USB 连接电脑；Windows 下为 COMx，Ubuntu 下为 ttyACM*
- Ubuntu 20.04 包内置 Qt 6.2.4；Ubuntu 22.04 包依赖系统 Qt 6；Windows 为免安装 ZIP

## 已知限制

- 语句「当前输出配置」依赖设备返回的 log 列表格式，解析不到时以界面上的手动设置为准
- 相机触发频率与 R1 天线的物理精度仍需外部仪器验证
