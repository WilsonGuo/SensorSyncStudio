# Sensor Sync Studio 1.0.4 发布说明

发布日期：2026-10-31
适用固件：Sensors-SYNC V3.1.0（协议 1.1）

本版本为 1.0.3 的界面修复版，未新增协议命令，固件无需升级。

## 修复

### 1. 高 DPI / 全屏下右侧栏被挤压重叠

在 Windows 150% 缩放（1858×1144 物理像素约等于 1240×763 逻辑像素）或窗口高度不足时，
右侧栏内容的最小高度超过可用空间，Qt 布局会把控件压扁并互相重叠，表现为：

- 「串口连接」的刷新 / 连接 / 保存日志按钮文字被裁切；
- 端口状态表最后一行与「端口与相机设置…」按钮叠在一起。

修复方式：

- 右侧栏整体放入滚动区域，空间不足时出现滚动条，不再挤压控件；
- 滚动区设定最小宽度 380 px，避免宽度也被压缩导致按钮横向裁切；
- 收紧右侧面板的内边距与间距（约省出 50 px）；
- 端口状态表改为内部滚动，优先保证整块面板可见；
- 窗口最小尺寸限制为 980×660。

### 2. 移除面板最小化按钮

「串口与设备」和「端口状态」面板右上角的「−」按钮已移除。右侧边缘的整栏折叠箭头（▶/◀）保留。
空间不足时右侧栏自动出现滚动条，不再需要逐面板折叠。

### 3. 端口状态面板入口调整

「端口与相机设置…」按钮移到面板右上角，窗口较矮时也不会被挤出可视区。

## 兼容性

- 协议、命令行、配置文件与 1.0.3 完全一致。
- Ubuntu 20.04 包内置 Qt 6.2.4；Ubuntu 22.04 包依赖系统 Qt 6；Windows 为免安装 ZIP。
- 1.0.3 → 1.0.4 可直接覆盖安装，无需迁移。

## 已知限制

- 相机触发频率、脉宽与四路相位仍需外部仪器实测。
- `$GETCONFIG`、`$GETPORTSTAT`、`$GETDEVICEINFO` 尚未在 V3.1.0 固件实现。
