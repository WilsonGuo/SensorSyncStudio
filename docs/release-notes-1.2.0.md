# Sensor Sync Studio 1.2.0 发布说明

发布日期：2026-11-24
适用固件：Sensors-SYNC V3.1.0（协议 1.1）
兼容硬件：GUNDA 多传感器同步器、R1 网络 RTK 模块

## 新增：外参换算工具

菜单「功能 → 外参换算」，离线使用，不依赖任何设备。

- **输入**：7 个数（`tx ty tz qx qy qz qw`）或 16 个数（4×4 矩阵，行优先），支持空格、逗号、换行分隔，粘贴即自动换算
- **输出**：平移、四元数（`qx qy qz qw` 与 `qw qx qy qz` 两种顺序）、旋转 3×3、RPY（deg, ZYX，与 ROS 约定一致）、TUM、4×4、NumPy 字面量，每行带「复制」按钮
- **求逆**：一键完成 Robot ⇄ Camera 的反向变换（Rᵀ 与 -Rᵀt），连点两次回到原值
- **归一化**：四元数模长偏离 1 时自动归一化并提示
- **姿态示意**：右侧实时绘制基准坐标系（灰）与当前姿态坐标系（彩色），用虚线连接并标注位移模长 |t|；支持拖拽旋转视角、滚轮缩放

## 界面修复

- 修正「4×4」输出框高度不足导致的滚动条
- 长文本输出行改为从首字符开始显示，避免开头被裁

## 兼容性

- 同步器协议、命令行与 1.1.0 完全一致，固件无需升级
- Ubuntu 20.04 包内置 Qt 6.2.4；Ubuntu 22.04 包依赖系统 Qt 6；Windows 为免安装 ZIP
- 外参换算纯本地计算，不涉及设备通信，不影响已连接的串口

## 已知限制

- 姿态示意的位移按比例缩放显示、不标刻度，仅用于核对方向和相对位置
- RPY 在接近万向锁（pitch ≈ ±90°）时对输入精度敏感，属正常现象
